# MedTrace

MedTrace is a blockchain-based pharmaceutical verification application built on Solana.

## Problem

Consumers often cannot easily verify the origin and supply-chain history of a medicine.

## Solution

MedTrace allows users to verify a pharmaceutical batch and see its verification status and supply-chain information.

## How it uses Solana

MedTrace uses Solana Devnet to record pharmaceutical verification data as a Memo transaction.

Each verification can contain:
- Medicine name
- Batch ID
- Manufacturer
- Verification status
- Current custodian

The blockchain record provides a public and independently verifiable proof of the verification.

## How to run

1. Open the MedTrace web application.
2. Connect a Phantom wallet configured for Solana Devnet.
3. Click "Verify medicine".
4. Confirm the transaction in Phantom.
5. Open the transaction in Solana Explorer.
